## Vì sao chọn CIT-PDF

- 🔒 **Riêng tư tuyệt đối.** Mọi xử lý diễn ra ngay trên máy. Không tải tệp lên máy chủ, không cần tài khoản, dùng được cả khi không có mạng.
- 🇻🇳 **Thuần Việt.** Giao diện, tên công cụ và hướng dẫn bằng tiếng Việt dễ hiểu. Nhận dạng chữ (OCR) hỗ trợ tiếng Việt có dấu.
- 🧰 **Đủ việc văn phòng.** Hơn 100 công cụ: gộp, tách, nén, chuyển Word/Excel/PowerPoint, OCR bản scan, ký số, đặt mật khẩu…
- 🆓 **Miễn phí, mã nguồn mở.** Phát hành theo giấy phép AGPL-3.0.

## Tính năng

### Làm việc ngay trên tài liệu đang mở

Mở một tệp PDF là có thể đọc, tìm kiếm, in, và xử lý luôn bằng các thẻ phía trên: **Đọc · Trang · Sửa · Chuyển đổi · Tối ưu & bảo mật**. Mở nhiều tệp cùng lúc, mỗi tệp một tab.

Thẻ **Trang** hiện toàn bộ trang dạng lưới: chọn bằng chuột (giữ Ctrl hoặc Shift để chọn nhiều), rồi xoay, xóa, trích ra tệp mới, chèn PDF hoặc trang trống, cuối cùng bấm **Lưu**.

### Và hơn nữa

- **Mở tệp từ Windows:** chuột phải một tệp `.pdf`, chọn **Open with › CIT-PDF** (hoặc đặt CIT-PDF làm ứng dụng mặc định). Nhiều tệp vẫn chỉ dùng một cửa sổ.
- **Cập nhật một bước:** khi có bản mới, ứng dụng hiện hộp thoại với nút **Cập nhật và khởi động lại**. Ứng dụng tự tải bản cài đặt, kiểm tra mã SHA-256 rồi cài đè.
- **Dùng được ở mạng bị chặn:** cài bộ xử lý từ một thư mục chép từ máy khác (Cài đặt › Bộ xử lý › _Cài từ thư mục…_).
- **Tiếng Việt hoặc English,** đổi trong Cài đặt.

## Cài đặt

Tải tại trang [**Releases**](https://github.com/Cuongyd196/cit-pdf/releases/latest).

| Hệ điều hành                  | Tệp                                            | Ghi chú                                                                                              |
| ----------------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Windows 10/11 (64-bit)        | `CIT-PDF-<phiên bản>-Windows-x64-Setup.exe`    | **Nên dùng.** Cài cho tài khoản đang đăng nhập, không cần quyền Administrator. Có cập nhật một bước. |
| Windows 10/11 (64-bit)        | `CIT-PDF-<phiên bản>-Windows-x64-Portable.exe` | Chạy thẳng không cần cài, chép được sang USB.                                                        |
| macOS (chip Apple M1 trở lên) | `CIT-PDF-<phiên bản>-macOS-arm64.dmg`          | Mở tệp, kéo CIT-PDF vào Applications.                                                                |
| macOS (chip Intel)            | `CIT-PDF-<phiên bản>-macOS-x64.dmg`            | Như trên.                                                                                            |
| Ubuntu / Debian               | `CIT-PDF-<phiên bản>-Linux-amd64.deb`          | `sudo apt install ./CIT-PDF-<phiên bản>-Linux-amd64.deb`                                             |
| Linux khác                    | `CIT-PDF-<phiên bản>-Linux-x86_64.AppImage`    | `chmod +x` rồi chạy, không cần cài.                                                                  |

Mỗi bản phát hành ghi kèm mã **SHA-256** của từng tệp để bạn đối chiếu.

> Các bộ cài chưa có chữ ký số của nhà phát hành.
>
> - **Windows** có thể hiện cảnh báo SmartScreen: bấm **More info › Run anyway**.
> - **macOS** chặn lần mở đầu: chuột phải vào CIT-PDF › **Open** › **Open**, hoặc chạy `xattr -cr /Applications/CIT-PDF.app` trong Terminal.
>
> Nút "Cập nhật và khởi động lại" hiện chỉ có trên bản cài Windows; trên macOS và Linux nút này mở trang tải.

### Bộ xử lý tải khi dùng lần đầu

Bộ cài chỉ chứa phần lõi (khoảng 145 MB). Các bộ xử lý nặng được tải một lần khi bạn dùng công cụ cần đến chúng, kiểm tra mã băm, rồi lưu trên máy để dùng cả khi không có mạng. Khi tải, ứng dụng hiện dung lượng, phần trăm và cho phép hủy.

| Bộ xử lý           | Dùng cho                                             | Nguồn                  | Kiểm tra         |
| ------------------ | ---------------------------------------------------- | ---------------------- | ---------------- |
| PyMuPDF            | PDF sang Word, Excel, văn bản                        | npm registry           | SHA-512          |
| Ghostscript        | Nén mạnh, PDF/A                                      | npm registry           | SHA-512          |
| LibreOffice        | Word, Excel, PowerPoint sang PDF                     | kho mã nguồn của dự án | SHA-256 từng tệp |
| Tesseract OCR      | Nhận dạng chữ trong bản scan (tiếng Việt, tiếng Anh) | có sẵn trong bộ cài    | không cần tải    |
| CoherentPDF (cpdf) | Xử lý trang                                          | có sẵn trong bộ cài    | không cần tải    |

Có thể tải trước toàn bộ hoặc xóa bớt cho nhẹ ổ đĩa trong **Cài đặt › Bộ xử lý**.

## Build từ mã nguồn

Cần Node.js 20 trở lên.

```bash
git clone https://github.com/Cuongyd196/cit-pdf.git
cd cit-pdf
npm install

npm run desktop              # build và chạy ứng dụng
npm run desktop:build        # chỉ build
npm run desktop:dist         # đóng gói bộ cài Windows vào release/
# macOS và Linux: workflow .github/workflows/desktop-release.yml (chạy tay với tag)
npm run desktop:modules-pack # gói bộ xử lý ngoại tuyến cho mạng bị chặn
```

Trong terminal của VS Code, biến `ELECTRON_RUN_AS_NODE=1` được đặt sẵn và làm Electron chạy như Node thường. Hãy bỏ biến này trước khi chạy `npm run desktop`.

Kiến trúc bản desktop được mô tả trong [DESKTOP.md](DESKTOP.md). Hướng dẫn gốc của BentoPDF cho bản web (Docker, self-host, cấu hình WASM) được giữ nguyên tại [README.bentopdf.md](README.bentopdf.md).

## Thay đổi so với BentoPDF

CIT-PDF là bản sửa đổi (fork) của [BentoPDF](https://github.com/alam00000/bentopdf) 2.8.8, do Cường IT đóng gói thành ứng dụng desktop trong năm 2026. Đây **không phải** sản phẩm chính thức của BentoPDF.

- Thêm lớp vỏ Electron (`desktop/`) với giao thức `app://` riêng để chạy ứng dụng không cần máy chủ web.
- Thêm trình quản lý bộ xử lý (`desktop/src/modules-manager.ts`): tải, kiểm tra mã băm, lưu trên máy, cho hủy giữa chừng, và cài từ gói ngoại tuyến.
- Thêm giao diện desktop (`src/js/desktop/`): thanh biểu tượng, trang chủ, trình xem có các thẻ làm việc và lưới trang, trang công cụ hai cột, hộp thoại cập nhật, cùng hai trang `cit-about.html` và `cit-settings.html`.
- Chạy PyMuPDF và Ghostscript trong worker để giao diện không bị đơ.
- Đổi tên, logo, ngôn ngữ mặc định (tiếng Việt) và Việt hóa tên công cụ.
- Thêm script build và cấu hình đóng gói (`scripts/build-desktop.mjs`, `electron-builder.json`).

Phần xử lý PDF của BentoPDF được giữ nguyên, kể cả dòng producer trong metadata của các tệp PDF xuất ra.
